# 1. Core Idea

## Recommended network representation

Instead of making a simple student-to-student network, construct an **opinion–opinion correlation network**.

### Nodes

Each survey statement is one node.

There are approximately **60 opinion statements**:

- `T01–T15` → Technology
- `E01–E15` → Education
- `S01–S15` → Social / Ethics
- `V01–V15` → Environment

The exact dataset dimensions and response counts should be verified programmatically before the final report.

### Edges

An edge connects two opinion statements when responses to those statements are strongly correlated across respondents.

For questions `i` and `j`:

\[
w_{ij} = Corr(X_i,X_j)
\]

where `Corr` is initially planned as Pearson correlation.

The response categories should be converted to an ordered numerical scale, for example:

\[
SD=-2,\quad D=-1,\quad N=0,\quad A=1,\quad SA=2
\]

where:

- `SD` = Strongly Disagree
- `D` = Disagree
- `N` = Neutral
- `A` = Agree
- `SA` = Strongly Agree

`No Comments` should be treated as missing rather than as a numerical opinion.

---

# 2. Why This Network Is Meaningful

The network answers a much more interesting question than "who is connected to whom?"

It asks:

> **Which opinions tend to move together across the class?**

A positive edge means that respondents who tend to agree with one statement also tend to agree with another.

A strong positive edge therefore represents a strong **opinion association**.

A negative correlation can represent an **opinion tension**: respondents who agree with one statement tend to disagree with another.

Important interpretation rule:

- Correlation shows association, **not causation**.
- The network describes the structure of the surveyed responses; it should not be generalized automatically to the entire student population.

---

# 3. Why We Should Not Use All Possible Edges

With 60 opinion nodes, the number of possible undirected edges is:

\[
\binom{60}{2}=1770
\]

Drawing all 1770 correlations would produce an extremely dense and visually unhelpful network.

## Proposed sparsification

Keep the **three strongest positive correlations for each node**.

This creates a sparse network while preserving the strongest relationships.

An initial analysis of the dataset indicated that this approach produces approximately:

- 60 nodes
- ~136 unique edges
- a connected main structure
- useful community structure

These numbers must be regenerated by the final implementation rather than hard-coded into the report.

### Important implementation detail

Because each node independently chooses its top 3 neighbors, the final number of unique edges can be less than 90 because:

\[
60\times3/2 = 90
\]

is only a rough upper intuition if every selection were symmetric; actual unique edges depend on reciprocal selections and the exact construction.

The code should:

1. calculate all pairwise correlations,
2. rank positive correlations for each node,
3. retain its top 3,
4. symmetrize the selected edges,
5. remove duplicate edges,
6. construct the final weighted graph.

Use at least the following.

---

## 12.1 Degree / Strength

For a weighted network:

\[
s_i=\sum_j w_{ij}
\]

This identifies opinions strongly associated with many other opinions.

Interpretation:

> A high-strength opinion is strongly connected to many other opinions in the constructed network.

---

## 12.2 Betweenness Centrality

Betweenness measures how frequently a node lies on shortest paths between other nodes.

Conceptually:

\[
C_B(v)
\propto
\sum_{s\neq v\neq t}
\frac{\sigma_{st}(v)}{\sigma_{st}}
\]

where:

- \(\sigma_{st}\) = number of shortest paths between \(s\) and \(t\),
- \(\sigma_{st}(v)\) = number of those paths passing through \(v\).

Interpretation:

> A high-betweenness opinion can act as a bridge between different groups of opinions.

The DPCN material explicitly covers betweenness and shortest-path based centrality.

---

## 12.3 Eigenvector Centrality

Eigenvector centrality gives more importance to connections with already important nodes.

Interpretation:

> An opinion can have high eigenvector centrality if it is connected to other highly connected/important opinions.

This is useful alongside degree because the two metrics answer different questions.

---

## 12.4 Closeness Centrality

Closeness can indicate how close an opinion is to the rest of the network through shortest paths.

Use with care if the graph is disconnected. The proposed top-3 network was initially observed to be connected, but this should be verified.

# 23. Better Null Model: Degree-Preserving Randomization

A stronger analysis is to compare the observed network with randomized networks that preserve the degree sequence.

Why?

An ER network only matches:

- number of nodes,
- approximately number of edges.

A degree-preserving null model keeps the observed degree sequence and randomizes the actual connections.

This provides a more controlled question:

> **Is the observed community/clustering structure stronger than expected simply from the degree distribution?**

This connects directly to the DPCN course's treatment of generalized/randomized network models.

---

# 29. Possible Alternative Edge Construction

If Pearson correlation is considered too sensitive to the numerical Likert encoding, consider a robustness check using **Spearman rank correlation**.

Main analysis:

\[
r^{Pearson}_{ij}
\]

\[

\]

The purpose is not to replace the main method unnecessarily but to check whether the strongest opinion relationships are broadly preserved.
